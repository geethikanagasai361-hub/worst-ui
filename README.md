# 🌀 OmniSynergy UltraPortal 3000™ - The Worst Possible UI

> **"Designed as if every established UX principle was deliberately and enthusiastically ignored."**

A fully functional, intentionally frustrating, chaotic, and absurd web application built to explore the absolute depths of user experience anti-patterns. Everything works—it's just agonizing to use.

---

## 🔥 Key UX Sufferings Included

- **Clashing Visual Aesthetics:** Neon lime, hot magenta, electric yellow, and 90s Windows gray with heavy 3D bevels, striped zebra gradients, and drop shadows.
- **Font Soup:** Random combinations of *Comic Neue*, *Impact*, *Press Start 2P*, *Cinzel/Times New Roman*, and *Courier Prime*.
- **Shuffling Navigation:** Navbar links rearrange their order periodically and upon being clicked. Deeply nested dropdowns requiring 4 levels of hovering.
- **Deceptive Controls & Runaway Buttons:** Buttons that physically evade the mouse cursor; visually identical buttons where one submits and the other clears your form; obstructive tooltips that block click targets.
- **The 5-Step Registration Gauntlet:**
  - **Step 1:** Reverse identity entry (Last name first, ALL-CAPS first name second), dog years slider (-12 to 180), enthusiastic hex color code picker.
  - **Step 2:** Live password validator enforcing 5 absurd rules (Roman numerals, chemical elements, anxious emojis, vowel bans on even positions) with an inverted strength meter; 0–120 dB acoustic pitch calibration slider; 10-digit phone number range slider (1,000,000,000 to 9,999,999,999).
  - **Step 3 (Turing Agony):** 3.00-second hold capacitor test (must release between 2.90s and 3.10s) and an existential traffic light CAPTCHA.
  - **Step 4 (Inverted Scroll Terms):** Inverted scrollbox EULA with double-negative consent checkboxes.
  - **Step 5 (Final Submit & Resets):** Fake slow loading screen that stalls at 99.4%, pauses, rewinds to 41%, and throws **Error 847**, wiping your fields and sending you back to Step 1!
- **Interactive Distractions:** Periodic toast alerts, Clippy-3000 AI Anti-Assistant chat, reversed 5-star satisfaction survey, and inescapable cookie banner with 450 fake partners.
- **Procedural Web Audio API:** Retro boings, buzzers, notification chimes, and decibel test tones synthesized in the browser without external files.
- **🕊️ The Secret Escape Hatch & Zen Mode:** A subtle dot hidden in the footer copyright notice (or pressing `Escape` 3 times) pauses the nightmare, calculates your **Trauma Score** (clicks wasted, popups endured, button chases), and offers total minimalist serenity.

## 🚀 Running Locally

Open `index.html` directly in any web browser:
```bash
# On Windows PowerShell:
Start-Process index.html
```

Or run the included lightweight PowerShell server:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
# Visit http://localhost:5173
```

## 🌐 Deploy to GitHub Pages

1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose the `main` branch and `/ (root)` folder, then click **Save**.
4. Your site will be live at: `https://geethikanagasai361-hub.github.io/worst-ui/`
